# mini-sklearn
## Overview
**mini-sklearn** is an accumulation of NumPy implementations of core ML algorithms (linear/ridge regression, logistic regression, k-means, gradient descent) built from scratch, with tests and docstrings, to understand the math behind scikit-learn's abstractions and get a better understanding of the various algorithms and their respective parameters.
